1 Executive Overview & Collaboration Scope

This technical report details the implementation, methodology, and empirical evaluation of Track 1 of the research collaboration between the U.S. Bureau of Labor Statistics (BLS) (Terrance D. Savitsky, Matthew R. Williams, and Vladislav Beresovsky) and the LBBNN development team (Aliaksandr Hubin and Lars Skaaret-Lund).

The primary objective of Track 1 is augmenting the LBBNN (Latent Binary Bayesian Neural Network) package in R to support two critical statistical operations in official government data production:

  1. Survey-Weighted Imputation & Modeling: Incorporating unit-indexed survey sampling weights \(w_i \propto \pi_i^{-1}\) (where \(\pi_i\) is the inclusion probability) into the variational Evidence Lower Bound (ELBO) objective. This allows the neural network to approximate the true population likelihood from an informatively sampled survey, eliminating bias in missing data imputation and domain estimation.
  2. Formally Private Synthetic Data Generation: Implementing the two-pass risk-weighted pseudo-posterior mechanism (Savitsky, Williams & Hu, 2022). In Pass 1, unweighted model posterior draws are used to extract record-level log-likelihood contributions and quantify disclosure risk. Symmetrically, record-specific privacy weights \(\alpha_i \in [0, 1]\) surgically downweight high-risk outliers during Pass 2, yielding synthetic microdata equipped with a mathematically provable local \((\epsilon, \delta)\)-probabilistic differential privacy (PDP) guarantee without degrading utility for safe observations.

2 Mathematical Framework

2.1 Variational Inference with Observation Weights

2.1.1 From Standard Posteriors to the Unit-Weighted Pseudo-Posterior

Let \(\mathbf{y} = (y_1, \dots, y_n)^\top \in \mathcal{Y}^n\) denote an observed dataset with associated auxiliary covariates \(\mathbf{X} = (\mathbf{x}_1, \dots, \mathbf{x}_n)^\top\). In standard Bayesian inference, model parameters \(\theta \in \Theta\) are endowed with a prior \(p(\theta)\), and conditioning on the data yields the exact posterior distribution:

\[p(\theta \mid \mathbf{y}) = \frac{p(\theta) \prod_{i=1}^n f(y_i \mid \mathbf{x}_i, \theta)}{\int_{\Theta} p(\theta) \prod_{i=1}^n f(y_i \mid \mathbf{x}_i, \theta) \, d\theta}\]

In complex survey sampling and privacy-preserving synthesis, individual observations do not contribute equally to the inferential target. To account for unequal survey selection probabilities or heterogeneous disclosure risks, we equip each observation \(i\) with a non-negative unit weight \(u_i \ge 0\), defining the unit-weighted pseudo-posterior distribution (Savitsky & Toth, 2016; Bhattacharya et al., 2019):

\[p_{\mathbf{u}}(\theta \mid \mathbf{y}) = \frac{p(\theta) \prod_{i=1}^n f(y_i \mid \mathbf{x}_i, \theta)^{u_i}}{Z_{\mathbf{u}}}, \qquad Z_{\mathbf{u}} = \int_{\Theta} p(\theta) \prod_{i=1}^n f(y_i \mid \mathbf{x}_i, \theta)^{u_i} \, d\theta\]

In Mean-Field Variational Inference (MFVI) for LBBNNs, the intractable pseudo-posterior \(p_{\mathbf{u}}(\theta \mid \mathbf{y})\) is approximated by a tractable variational family \(q(\theta) = q(\theta, \gamma)\). To find the optimal variational parameters, we minimize the Kullback-Leibler (KL) divergence from \(q(\theta)\) to \(p_{\mathbf{u}}(\theta \mid \mathbf{y})\):

\[\begin{aligned} \text{KL}\big(q(\theta) \parallel p_{\mathbf{u}}(\theta \mid \mathbf{y})\big) &= \mathbb{E}_{q(\theta)}\left[\log q(\theta) - \log p_{\mathbf{u}}(\theta \mid \mathbf{y})\right] \\ &= \mathbb{E}_{q(\theta)}[\log q(\theta)] - \mathbb{E}_{q(\theta)}\left[\log p(\theta) + \sum_{i=1}^n u_i \log f(y_i \mid \mathbf{x}_i, \theta) - \log Z_{\mathbf{u}}\right] \\ &= \text{KL}\big(q(\theta) \parallel p(\theta)\big) - \sum_{i=1}^n u_i \, \mathbb{E}_{q(\theta)}\!\left[\log f(y_i \mid \mathbf{x}_i, \theta)\right] + \log Z_{\mathbf{u}} \end{aligned}\]

Because the marginal normalizing constant \(Z_{\mathbf{u}}\) does not depend on the variational distribution \(q(\theta)\), minimizing \(\text{KL}\big(q(\theta) \parallel p_{\mathbf{u}}(\theta \mid \mathbf{y})\big)\) is mathematically equivalent to maximizing the unit-weighted Evidence Lower Bound (ELBO):

\[\text{ELBO}(q; \mathbf{u}) = \sum_{i=1}^n u_i \, \mathbb{E}_{q(\theta)}\!\left[\log f(y_i \mid \mathbf{x}_i, \theta)\right] - \text{KL}\big(q(\theta) \parallel p(\theta)\big)\]

2.1.2 Mini-Batch Alignment & ELBO Scaling

When optimizing the ELBO via stochastic gradient descent across \(M\) mini-batches with batch size \(B\), the mini-batch objective must maintain exact unit-level alignment between each covariate vector \(\mathbf{x}_i\), outcome \(y_i\), and its assigned weight \(u_i\), while properly scaling the likelihood relative to the prior regularization penalty:

\[\text{ELBO}_{\text{batch}}(q; \mathbf{u}) = \sum_{i \in \text{batch}} u_i \, \log f(y_i \mid \mathbf{x}_i, \theta) - \frac{1}{M} \text{KL}\big(q(\theta) \parallel p(\theta)\big)\]

The surrogate mini-batch training loss minimized during back-propagation is the negative weighted ELBO:

\[\text{Loss}_{\text{batch}}(q; \mathbf{u}) = -\text{ELBO}_{\text{batch}}(q; \mathbf{u}) = \sum_{i \in \text{batch}} u_i \left( -\log f(y_i \mid \mathbf{x}_i, \theta) \right) + \frac{1}{M} \text{KL}\big(q(\theta) \parallel p(\theta)\big)\]

When \(u_i = 1\) for all \(i = 1, \dots, n\), this formulation is 100% numerically identical to standard unweighted variational training.

2.1.3 Survey Weight Normalization vs. Privacy Weight Scaling

A critical operational distinction exists between survey sampling weights (\(w_i\)) and differential privacy weights (\(\alpha_i\)):

  1. Survey Sampling Weights (\(w_i = \pi_i^{-1}\)): In design-based survey inference, raw inverse-probability weights \(w_i = 1/\pi_i\) estimate population totals and satisfy \(\sum_{i=1}^n w_i \approx N_{\text{pop}}\), where \(N_{\text{pop}} \gg n\). If raw weights were inserted directly into the ELBO, the weighted log-likelihood term would scale with \(N_{\text{pop}}\), overpowering the prior \(\text{KL}\big(q(\theta) \parallel p(\theta)\big)\) regularization penalty by a factor of \(N_{\text{pop}} / n\). Following Savitsky & Toth (2016), we normalize survey weights to sum to the observed sample size \(n\): \[\tilde{w}_i = w_i \times \frac{n}{\sum_{j=1}^n w_j}\] This normalization ensures the effective sample size in the variational pseudo-posterior matches \(n\), preserving the intended balance between data evidence and prior regularization. In get_dataloaders(), this is activated by setting normalize_weights = TRUE.

  2. Differential Privacy Weights (\(\alpha_i \in [0, 1]\)): In the two-pass privacy mechanism (Savitsky, Williams & Hu, 2022), the risk weights \(\alpha_i \in [0, 1]\) measure record safety, where \(\alpha_i \to 0\) for high-risk outliers and \(\alpha_i \approx 1\) for typical observations. Here, \(\sum_{i=1}^n \alpha_i \le n\). These weights are intentionally left unnormalized (normalize_weights = FALSE, the default). Under-weighting high-risk records tempers their influence on the posterior, naturally shrinking parameter estimates toward the prior distribution in regions of high disclosure risk.

2.1.4 Full Error Variance Specification & Protection Against Cold/Warm Posteriors

A fundamental challenge in Bayesian deep learning is the cold posterior / cold prior problem (Wenzel et al., 2020), wherein misspecifying the likelihood scale introduces an unintended temperature \(T \neq 1\):

\[\mathcal{L}_{\text{ELBO}}(q) = \frac{1}{T} \sum_{i=1}^n u_i \, \mathbb{E}_{q(\theta)}\!\left[\log f(y_i \mid \mathbf{x}_i, \theta)\right] - \text{KL}\big(q(\theta) \parallel p(\theta)\big)\]

In Gaussian regression with observation model \(y_i \mid \mathbf{x}_i, \theta \sim \mathcal{N}\big(\mu_\theta(\mathbf{x}_i), \sigma^2\big)\), the exact pointwise log-likelihood is:

\[\log f(y_i \mid \mathbf{x}_i, \theta, \sigma^2) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{\big(y_i - \mu_\theta(\mathbf{x}_i)\big)^2}{2\sigma^2}\]

Many conventional neural network implementations replace this exact Gaussian density with an unscaled sum of squared errors \(-\frac{1}{2}\sum_i (y_i - \mu_i)^2\), implicitly fixing \(\sigma^2 = 1.0\) (precision \(\tau = 1.0\)). Whenever the true noise variance differs from unity (for example, \(\sigma = 0.40 \implies \sigma^2 = 0.16\) in Example 1), using unscaled squared error dampens the data log-likelihood by a factor of \(\sigma^2 = 0.16\) relative to the prior KL divergence:

\[\frac{1}{2} (y_i - \mu_i)^2 = 0.16 \times \left[ \frac{(y_i - \mu_i)^2}{2 \times 0.16} \right]\]

This mis-scaling acts as an unintended hot prior / cold posterior temperature (\(T = \sigma^2 = 0.16 < 1\)), artificially over-regularizing the model and distorting the spike-and-slab inclusion probabilities \(a_k\) toward zero.

Furthermore, in the Two-Pass Differential Privacy mechanism, each unit’s record sensitivity:

\[f_i = \max_{s \in \{1,\dots,S\}} \left| \log f(y_i \mid \mathbf{x}_i, \theta^{(s)}, \sigma^2) \right|\]

directly depends on the residual scale \(\sigma^2\). If \(\sigma^2\) is misspecified, sensitivities are measured on an arbitrary scale, invalidating the empirical privacy guarantee \(\epsilon_{\mathbf{y}} = 2\Delta_{\alpha, \mathbf{y}}\). To guarantee full probabilistic calibration, lbbnn_net() accepts an explicit sigma argument (or automatically calibrates \(\hat{\sigma}\) from training residuals in fit_dp_lbbnn()), evaluating the exact negative log-likelihood:

\[\text{NLL}_i = \frac{1}{2}\log(2\pi\sigma^2) + \frac{(y_i - \mu_\theta(\mathbf{x}_i))^2}{2\sigma^2}\]

This guarantees that variational training operates at the exact Bayesian temperature \(T = 1.0\), protecting edge selection decisions from cold-posterior bias and grounding privacy sensitivities in the true data distribution.

2.1.5 Domain-Level Estimation & Observation Error De-Noising

Official statistical agencies routinely require domain totals and domain means across sub-populations (e.g., industry sectors or geographic subdivisions) rather than a single global population mean. Let \(\mathbf{G} \in \mathbb{R}^{n \times D_{\text{dom}}}\) denote a binary or fractional domain membership matrix, where \(G_{i,d} = 1\) if unit \(i\) belongs to domain \(d \in \{1, \dots, D_{\text{dom}}\}\).

The design-weighted domain mean and total are given by:

\[\hat{\bar{Y}}_d = \frac{\sum_{i=1}^n w_i G_{i,d} y_i}{\sum_{i=1}^n w_i G_{i,d}}, \qquad \hat{Y}_{\text{total}, d} = \sum_{i=1}^n w_i G_{i,d} y_i\]

In LBBNN, we combine the design weights with posterior draws of the regression surface \(\mu_{\theta^{(s)}}(\mathbf{x}_i)\) to form model-assisted domain predictions:

\[\hat{\bar{Y}}_d^{\text{BNN}(s)} = \frac{\sum_{i=1}^n w_i G_{i,d} \hat{\mu}_i^{(s)}}{\sum_{i=1}^n w_i G_{i,d}}\]

Observation Noise De-Noising: While spike-and-slab edge selection prunes pure noise covariates (\(X_3, X_4\)), additive unit-level observation error \(\varepsilon_i \sim \mathcal{N}(0, \sigma^2)\) in \(y_i = \mu(\mathbf{x}_i) + \varepsilon_i\) cannot be isolated from idiosyncratic unit variation without repeated measurements. However, by substituting the posterior conditional expectation \(\hat{\mu}_i^{(s)} = \mu_{\theta^{(s)}}(\mathbf{x}_i)\) (type = "latent_mean") in place of noisy predictive draws \(\tilde{y}_i^{(s)} = \mu_{\theta^{(s)}}(\mathbf{x}_i) + \varepsilon_i^{(s)}\) (type = "predictive"), predict_domains_lbbnn() explicitly removes additive measurement noise, yielding an error-free estimate of the underlying latent regression surface.

2.1.6 Bayesian Imputation for Missing Survey Responses (\(y_i = \text{NA}\))

Item non-response is pervasive in survey sampling. In LBBNN, we partition sample units into observed units \(S_{\text{obs}} = \{i : \text{!is.na}(y_i)\}\) and missing units \(S_{\text{mis}} = \{i : \text{is.na}(y_i)\}\). During variational optimization (get_dataloaders(..., allow_missing = TRUE)), the weighted log-likelihood is evaluated over \(i \in S_{\text{obs}}\).

Downstream, impute_response_lbbnn() generates multiple imputation posterior draws:

\[\tilde{y}_i^{(s)} \sim \mathcal{N}\big(\mu_{\theta^{(s)}}(\mathbf{x}_i), \sigma^2\big), \qquad i \in S_{\text{mis}}, \quad s \in \{1, \dots, S\}\]

These draws capture both parameter uncertainty (variation in \(\theta^{(s)} \sim q(\theta)\)) and residual sampling uncertainty (calibrated \(\sigma^2\)).

2.1.7 Correcting Pseudo-Posterior Variance Deficits via Dirichlet Bayesian Bootstrap

Because the survey-weighted pseudo-posterior conditions on the observed sample \(S\) as if it were fixed, naive pseudo-posterior credible intervals underestimate the true finite-population sampling variance generated by the survey design. Following Savitsky & Toth (2016), we calibrate posterior intervals by sampling flat Dirichlet perturbations for each draw \(s \in \{1, \dots, S\}\):

\[\boldsymbol{\xi}^{(s)} = \big(\xi_1^{(s)}, \dots, \xi_n^{(s)}\big) \sim \text{Dirichlet}(1, \dots, 1)\]

implemented via normalized Exponential draws: \(\xi_i^{(s)} = E_i^{(s)} / \sum_{j=1}^n E_j^{(s)}\) with \(E_i^{(s)} \stackrel{\text{i.i.d.}}{\sim} \text{Exp}(1)\). Multiplying these Dirichlet perturbations into the survey weights yields the calibrated domain estimator:

\[\hat{\bar{Y}}_d^{(s)} = \frac{\sum_{i=1}^n \xi_i^{(s)} w_i G_{i,d} y_i^{(s)}}{\sum_{i=1}^n \xi_i^{(s)} w_i G_{i,d}}\]

In predict_domains_lbbnn(..., dirichlet_uq = TRUE) and hajek_estimate(..., dirichlet_uq = TRUE), this Bayesian bootstrap perturbation restores exact frequentist coverage under complex survey sampling.

2.2 Two-Stage Differential Privacy Calibration (Savitsky, Oct 29, 2026)

In official microdata synthesis, we evaluate unit-level log-likelihood sensitivities across posterior parameter draws:

\[f_i = \max_{s \in \{1, \dots, S\}} \left| \log f(y_i \mid \mathbf{x}_i, \theta^{(s)}) \right|, \qquad f_{\min} = \min_{j=1, \dots, n} f_j, \quad f_{\max} = \max_{j=1, \dots, n} f_j\]

Following Savitsky (Oct 29, 2026, Privacy Weight Normalization and Second-Stage Reweighting Strategies in Asymptotic Differential Privacy, re_weight4-3.pdf), privacy weights \(\alpha_i\) are calibrated in two modular stages. Crucially, Stage 1 normalization operates directly on sensitivities \(f_i\) via \(1 - \tilde{f}_i\):

2.2.1 Stage 1: Initial Privacy Weight Normalization on \(f_i\) (stage1_method)

  1. Method 1 ("linear") — Direct Linear Min-Max on \(f_i\) (Savitsky et al., 2022, Eq. 4–5): \[\tilde{f}_i = \frac{f_i - f_{\min}}{f_{\max} - f_{\min}} \in [0, 1], \qquad \alpha_i^{\text{lin}} = \text{clip}_{[0, 1]}\!\left(c \cdot (1 - \tilde{f}_i) + g\right) = \text{clip}_{[0, 1]}\!\left(c \left(\frac{f_{\max} - f_i}{f_{\max} - f_{\min}}\right) + g\right)\] where \(c \in (0, 1]\) controls scaling and \(g \ge 0\) allows a baseline shift.

    Remark 1 (Direct \(1 - \tilde{f}_i\) vs. Reciprocal Transformation \(1/f_i\), Eq. 8–9): Normalizing reciprocal sensitivities \(\tilde{\alpha}_i = 1/f_i\) yields: \[\alpha_i^{\text{recip}} = \left(\frac{f_{\min}}{f_i}\right) \alpha_i^{\text{lin}} < \alpha_i^{\text{lin}} \quad \forall f_i \in (f_{\min}, f_{\max})\] which introduces an aggressive hyperbolic penalty \((f_{\min}/f_i)\) that severely attenuates weights and collapses all intermediate observations if \(f_{\min} \to 0\). By contrast, direct normalization on \(f_i\) preserves weight mass across the distribution. Although the unit contribution \(\alpha_i^{\text{lin}} f_i\) is parabolic in \(f_i\) with an interior peak at \(f_{\max}/2\), this peak is strictly bounded: \(\max_i \alpha_i^{\text{lin}} f_i \le \frac{c}{4} f_{\max}\), which can be capped in Stage 2.

  2. Method 2 ("percentile") — Percentile Deficit Truncation on \(f_i\) (Eq. 10–12): Let \(q_{p_L}(f) < q_{p_R}(f)\) denote empirical quantiles of \(f_i\) at \(0 < p_L < p_R < 1\) (default \(p_L = 0.05, p_R = 0.95\)): \[\tilde{f}_i^{\text{pct}} = \frac{f_i - q_{p_L}(f)}{q_{p_R}(f) - q_{p_L}(f)}, \qquad \alpha_i^{\text{pct}} = \min\!\left(1, \, \max\!\left(0, \, 1 - \tilde{f}_i^{\text{pct}}\right)\right) = \min\!\left(1, \, \max\!\left(0, \, \frac{q_{p_R}(f) - f_i}{q_{p_R}(f) - q_{p_L}(f)}\right)\right)\]

    • Low Sensitivity Inliers (\(f_i \le q_{p_L}(f)\)): Receive full weight \(\alpha_i^{\text{pct}} = 1\).
    • Intermediate Units (\(q_{p_L}(f) < f_i < q_{p_R}(f)\)): Decay linearly in \((0, 1)\).
    • High Sensitivity Outliers (\(f_i \ge q_{p_R}(f)\)): Hard-truncated to \(\alpha_i^{\text{pct}} = 0\). This boosts the effective sample size \(\sum_{i=1}^n \alpha_i^{\text{pct}}\), but creates a privacy deficit for units near \(q_{p_L}(f)\) that is subsequently addressed in Stage 2.

  3. Method 3 ("target_clip") — Target Ratio Clipping (\(\Delta_{i,\text{goal}}\) Ratio Clipping, Eq. 13): Given sensitivity goal \(\Delta_{i,\text{goal}} > 0\) (defaulting to \(M_{\text{thresh}}\)): \[\alpha_i^{\text{clip}} = \min\!\left(1, \, \frac{\Delta_{i,\text{goal}}}{f_i}\right)\] Properties (Proposition 1 of Savitsky, 2026): Guarantees exact sensitivity control \(\alpha_i^{\text{clip}} f_i = \min(f_i, \Delta_{\text{goal}}) \le \Delta_{\text{goal}}\) by construction, leaving all low-sensitivity records (\(f_i \le \Delta_{\text{goal}}\)) untouched at \(\alpha_i^{\text{clip}} = 1\).

2.2.2 Stage 2: Second-Stage Reweighting Schemes (stage2_method)

Given Stage 1 weights \(\boldsymbol{\alpha}\) and sensitivity threshold \(M_{\text{thresh}} > 0\), enforce \(\alpha_i^* f_i \le M_{\text{thresh}}\):

  1. Scheme 1 ("hard_trunc") — Hard Threshold Truncation (Eq. 16): \[\alpha_i^{\text{trunc}} = \alpha_i \, \mathbb{I}(\alpha_i f_i \le M_{\text{thresh}})\] Single-pass post-hoc zeroing of records exceeding \(M_{\text{thresh}}\). Discards privacy slack (\(M_{\text{thresh}} - \alpha_i f_i\)).

  2. Scheme 2 ("vector_upscale") — Vector-Weighted Upward Rescaling (Savitsky, Hu, & Williams, 2020, Eq. 17–18): \[\alpha_i^{\text{vec}} = \min\!\left(1, \, \alpha_i \cdot \frac{M_{\text{thresh}}}{\alpha_i f_i}\right) = \min\!\left(1, \, \frac{M_{\text{thresh}}}{f_i}\right)\] Properties (Proposition 2 of Savitsky, 2026): Pointwise dominates hard truncation (\(\alpha_i^{\text{vec}} \ge \alpha_i^{\text{trunc}}\) for all \(i\)), maximizing Fisher information \(\mathcal{I}_{\boldsymbol{\alpha}^{\text{vec}}}(\theta) \succeq \mathcal{I}_{\boldsymbol{\alpha}^{\text{trunc}}}(\theta)\) in the Loewner partial order. Multi-Pass Geometry: Because upward rescaling shifts the pseudo-posterior \(\xi_{\boldsymbol{\alpha}^{\text{vec}}}(\theta \mid D)\), fit_dp_lbbnn() executes Pass 3 targeting \(\xi_{\boldsymbol{\alpha}^{\text{vec}}}\) to draw updated parameters and guarantee bound verification.

  3. Scheme 3 ("surgical"): Monotone capping \(\alpha_i = \min(\alpha_i^{\text{raw}}, M_{\text{thresh}} / f_i)\) with zeroing when \(f_i > 3 M_{\text{thresh}}\) for backward reproducibility.

3 Example 1: Survey-Weighted Imputation Under Informative Sampling

3.1 Simulating an Informatively Sampled Population

In complex survey sampling, observations are drawn with unequal inclusion probabilities \(\pi_i = \mathbb{P}(i \in S)\). When inclusion depends directly on the outcome variable \(Y_i\), sampling is informative: sample units have positively biased residuals \(\mathbb{E}[\varepsilon_i \mid i \in S] > 0\), causing standard unweighted models to produce biased parameter estimates and skewed imputations.

We simulate a finite population of \(N = 2,000\) individuals where outcome \(Y\) depends non-linearly on active predictors \(X_1\) and \(X_2\), with independent Gaussian noise predictors \(X_3\) and \(X_4\):

\[Y_i = 2.0 X_{1i} + 1.5 \sin(\pi X_{2i}) + 0.8 X_{1i} X_{2i} + \varepsilon_i, \quad \varepsilon_i \sim \mathcal{N}(0, 0.4^2)\]

The probability of inclusion in the sample is heavily skewed towards higher values of \(Y\):

\[\pi_i = \text{logit}^{-1}\big(-1.0 + 1.2 Y_i\big)\]

# Generate population
N_pop <- 2000
x1_pop <- rnorm(N_pop, 0, 1)
x2_pop <- runif(N_pop, -1, 1)
x3_pop <- rnorm(N_pop, 0, 1) # noise
x4_pop <- rnorm(N_pop, 0, 1) # noise

y_pop <- 2.0 * x1_pop + 1.5 * sin(pi * x2_pop) + 0.8 * x1_pop * x2_pop + rnorm(N_pop, 0, 0.4)
true_pop_mean <- mean(y_pop)

# Informative sampling mechanism
pi_inc <- plogis(-1.0 + 1.2 * y_pop)
pi_inc <- pmax(pi_inc, 0.05) # bound away from zero

# Draw sample
in_sample <- rbinom(N_pop, 1, pi_inc) == 1
n_smp <- sum(in_sample)

sample_df <- data.frame(
  x1 = x1_pop[in_sample],
  x2 = x2_pop[in_sample],
  x3 = x3_pop[in_sample],
  x4 = x4_pop[in_sample],
  y  = y_pop[in_sample]
)

# Survey sampling design weights
weights_survey <- 1 / pi_inc[in_sample]

cat(sprintf("Population Size: %d | True Pop Mean Y: %.3f\n", N_pop, true_pop_mean))
cat(sprintf("Sample Size: %d | Unweighted Sample Mean: %.3f (Bias: +%.3f)\n", 
            n_smp, mean(sample_df$y), mean(sample_df$y) - true_pop_mean))
cat(sprintf("Hajek Weighted Sample Mean: %.3f (Bias: %+.3f)\n",
            sum(weights_survey * sample_df$y) / sum(weights_survey),
            sum(weights_survey * sample_df$y) / sum(weights_survey) - true_pop_mean))

3.2 Fitting Unweighted vs. Survey-Weighted LBBNN

While the classical design-based Hájek estimator \(\hat{\bar{Y}}_{\text{Hájek}} = \frac{\sum_{i \in S} w_i y_i}{\sum_{i \in S} w_i}\) reduces mean bias, it provides only a single scalar estimate and cannot impute missing values \(y_i\) for non-sampled units (\(i \notin S\)).

To impute missing values across the population, we fit: 1. Unweighted LBBNN: Fits directly on the biased sample data. 2. Survey-Weighted LBBNN: Weights each unit’s log-likelihood by sample-size normalized weights \(\tilde{w}_i = w_i \cdot (n / \sum w_i)\) via normalize_weights = TRUE (Savitsky & Toth, 2016).

# Model specification with calibrated observation noise sigma = 0.40
spec_survey <- list(
  problem_type = "regression",
  sizes = c(4, 16, 16, 1),
  prior = c(0.2, 0.2, 0.2), # Prior inclusion probabilities
  std = c(1.0, 1.0, 1.0),

4.2 Running the Two-Pass DP Synthesizer (fit_dp_lbbnn)

We synthesize on the properly specified log scale \(\log(Y)\) using fit_dp_lbbnn(): - Pass 1: Fits an unweighted model and automatically estimates the residual noise scale \(\hat{\sigma} = \text{sd}(y - \hat{y}_{\text{p1}})\) (sigma = NULL). - Monotone Surgical Weights: Evaluates record sensitivities \(f_i = \max_s |L_{s, i}|\) with calibrated \(\hat{\sigma}\), computes smooth weights \(\alpha_i \in [0, 1]\) (\(c_{\text{scale}} = 0.85\), \(g_{\text{shift}} = 0.0\)), caps weights at \(M_{\text{thresh}} / f_i\), and surgically zeroes extreme tail outliers (\(f_i > 3 M_{\text{thresh}}\)). - Pass 2: Fits a fresh model weighted by \(\alpha_i\) (normalize_weights = FALSE). - Guarantee: Evaluates the local Lipschitz bound \(\Delta_{\alpha, \mathbf{y}} \le M_{\text{thresh}}\) and local differential privacy parameter \(\epsilon_{\mathbf{y}} = 2 \Delta_{\alpha, \mathbf{y}}\).

spec_dp <- list(

  device = "cpu"
)

5 Example 3: Custom Composite Likelihood Integration

The problem_type = "custom" functionality allows users to supply custom link and negative log-likelihood (NLL) functions. This serves as the direct architectural bridge to Track 2 (Vladislav Beresovsky’s composite Bernoulli likelihoods for combining probability and non-probability samples).

Specifically, during train_lbbnn(), the training loop evaluates self$nll(input, target, reduction = "none") when unit weights \(u_i\) are present (multiplying each observation’s loss contribution \(\ell_i\) by \(u_i\) before summation), and loglik_contributions() evaluates reduction = "none" to populate the \(S \times n\) sensitivity matrix \(L_{s,i} = -\ell_i(\theta^{(s)})\). This unified interface allows LBBNN to seamlessly optimize multi-column targets cbind(I_z, pi_r) in Track 2 (nll_stack, nll_link1, nll_link2, make_nll_mip, nll_pseudo).

# Define custom link: Sigmoid activation
custom_sigmoid_link <- function(x) torch::torch_sigmoid(x)

# Define custom negative log-likelihood with numerical clamping
custom_bce_nll <- function(input, target, reduction = "sum") {
  eps <- 1e-7
  p_hat <- torch::torch_clamp(input, eps, 1.0 - eps)
  t_flt <- target$squeeze()$to(dtype = torch::torch_float32())
  p_flt <- p_hat$squeeze()
  
  # Pointwise Bernoulli NLL
  nll_i <- -(t_flt * torch::torch_log(p_flt) + (1.0 - t_flt) * torch::torch_log(1.0 - p_flt))
  
  if (reduction == "none") {
    return(nll_i)
  } else {
    return(torch::torch_sum(nll_i))
  }
}

# Instantiate custom model
custom_model <- lbbnn_net(
  problem_type = "custom",
  sizes = c(3, 8, 1),
  prior = c(0.5, 0.5),
  std = c(1.0, 1.0),
  inclusion_inits = "balanced",
  link = custom_sigmoid_link,
  nll = custom_bce_nll,
  device = "cpu"
)

# Synthetic binary task

y_cust <- rbinom(60, 1, 0.5)
dl_cust <- torch::dataloader(
  torch::tensor_dataset(torch::torch_tensor(x_cust), torch::torch_tensor(y_cust)),
  batch_size = 20,
  shuffle = FALSE

# Train model
